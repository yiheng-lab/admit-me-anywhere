# Admit Me Anywhere

> 想去哪，填哪。

一个纯前端的 admission parody generator。

真正的录取结果由系统决定，这个不是。

填学校、填专业、填导师、填成绩，看看另一条时间线里的你去了哪里。

## Demo

GitHub Pages:

https://yiheng-lab.github.io/admit-me-anywhere/

## Features

- 自定义学校、院系、专业、导师、成绩和通知文案
- 实时预览
- 导出 PNG
- 纯前端运行
- 不需要账号
- 不需要服务器
- 不连接任何招生数据库
- 用户填写的数据不会上传到本站

## How it works

本项目只是一个静态网页。

所有字段的编辑与页面渲染均发生在用户浏览器中。

不存在：

- 教育部接口
- 学信网接口
- 高校招生接口
- 用户数据库
- 录取状态查询
- 录取状态修改

因此，本项目不会也不能改变任何真实的招生或录取结果。

## Disclaimer

本项目为独立的虚构娱乐项目，与教育部、学信网、任何高校及其他招生机构均无关联、授权或背书关系。

生成内容不具有任何官方证明效力。

所有导出结果固定带有：

> 虚构内容 · PARODY · 非官方网站

请勿将生成内容用于欺骗、冒充官方材料或其他违法用途。

## Privacy

所有用户输入均在浏览器本地处理。

本站没有用于收集这些字段的后端服务器或数据库。

PNG 导出功能可能通过 CDN 加载前端依赖，但用户填写的录取字段不会因此上传至本站。
